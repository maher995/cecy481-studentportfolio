# 05 StudentPortfolio

**CECY481-Software Security — intentionally vulnerable training application**

Student portfolio and feedback service. This is an unfamiliar codebase for your security assessment project.

## Run locally

```bash
python -m venv .venv
# Activate the virtual environment for your OS
pip install -r requirements.txt
python app.py
```

Open the localhost URL shown in the terminal. Requires Python 3.10+. Do not deploy publicly.

## Your tasks

1. Identify entry points, assets, and trust boundaries.
2. Use at least two complementary analysis techniques, including one automated tool.
3. Investigate at least three security weaknesses or suspected vulnerabilities.
4. Record evidence, CWE, impact, proposed defense, and verification plan.
5. Implement and retest two fixes if feasible.

## Rules

Only test this local application in your own authorized lab environment. Do not target external sites. The dataset and credentials are fictional.
